## 📋 Project Portfolio & Engineering Breakdown

Every single application within this repository was designed from scratch to solve specific logical and structural front-end challenges.

### 1. 🧮 JavaScript Calculator (`/calculator`)
* **The Challenge:** Build a fully functional, precise calculator handling sequential arithmetic calculations.
* **Key Implementations:** Solved edge cases regarding formula vs. immediate-execution logic, decimal point multi-entries, and sequential negative operators using precise string/numerical expression evaluation algorithms in React state.

### 2. ⏱️ 25 + 5 Clock (`/clock`)
* **The Challenge:** Implement a productivity timer (Pomodoro technique) featuring separate session and break countdowns.
* **Key Implementations:** Leveraged asynchronous JavaScript (`setInterval`), strict state synchronization to prevent timer drifting, audio element manipulation for alarms, and dynamic play/pause/reset states.

### 3. 🥁 Drum Machine (`/drum-machine`)
* **The Challenge:** A real-time, highly responsive audio pads application.
* **Key Implementations:** Mapped global keyboard event listeners alongside click events to trigger audio elements with sub-millisecond latency. Managed dynamic UI sound-bank switching and volume adjustment states.

### 4. 📝 Markdown Previewer (`/markdown-previewer`)
* **The Challenge:** A real-time, split-screen text editor that renders Markdown syntax into valid HTML on the fly.
* **Key Implementations:** Integrated external parsing libraries safely into the React ecosystem, sanitizing input to prevent XSS (Cross-Site Scripting) while keeping rendering synchronized with typing input.

### 5. 💬 Random Quote Machine (`/quote-machine`)
* **The Challenge:** A dynamic UI component that fetches, displays, and shares inspirational quotes.
* **Key Implementations:** Managed asynchronous API data fetching (`fetch`/`Axios`), dynamic state transitions, and third-party Web Intent integrations (e.g., dynamic Twitter/X sharing links).

## 💻 Getting Started & Installation
To run any of these applications locally, clone the repository and navigate to the project directory.
```bash
# 1. Clone the repository using the exact path
git clone [https://github.com/Bore237/freecodecamp-frondEnd-project.git](https://github.com/Bore237/freecodecamp-frondEnd-project.git)

# 2. Navigate to the desired project folder (e.g., Drum Machine)
cd freecodecamp-frondEnd-project/drum-machine

# 3. Install dependencies and spin up the local development server
npm install
npm start
```
